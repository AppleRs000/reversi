# リバーシ

ブラウザで遊べるリバーシ（オセロ）です。サーバー不要の静的サイトなので、GitHub Pagesでそのまま公開できます。

## 遊び方

- **対戦モード**：2人対戦 / CPU（弱い・普通・強い）
- CPU戦では先手（黒）・後手（白）を選べます
- **対戦中のボタン**
  - パス：置ける場所がないときに使います（置ける場所があるときは押せません）
  - アシスト：置ける場所に印を表示します（ON/OFF切り替え）
  - 降参：現在の手番のプレイヤーの負けで終局します（CPU戦ではあなたの負け）
  - 一時停止 / 再開：盤面を隠して対局を止めます
  - 停止：対局を中断します（勝敗には記録されません）
  - 終了：メニューに戻ります
- **勝敗数**：モードごとにブラウザ内（localStorage）へ保存され、メニュー画面と対局画面で確認できます

## CPUの強さ

| レベル | 内容 |
| --- | --- |
| 弱い | 置ける場所からランダムに選ぶ |
| 普通 | 場所の価値を使って2手先まで読む |
| 強い | 着手可能数も評価して5手先まで読み、残り8マス以下は最後まで読み切る |

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`reversi`）
2. このフォルダの `index.html` / `style.css` / `script.js` / `README.md` をリポジトリ直下にアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** の Source を `Deploy from a branch` にし、Branch を `main`、フォルダを `/ (root)` にして Save
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## ファイル構成

```
index.html   画面
style.css    見た目
script.js    ルール・CPU・画面操作
```
